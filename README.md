# University Website

A modern, responsive university website built with React.js and Vite, featuring academic programs, campus gallery, student testimonials, and a contact form.

## Features
- Responsive layout for all devices
- Interactive navigation and video player
- Programs and campus gallery
- Student testimonials
- Functional contact form

## Tech Stack
React.js, Vite, JavaScript, CSS Modules, Web3Forms
